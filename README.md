# 학교탈출: 감시자의 밤

스토리 선택형 학교 탈출 공포게임의 웹/PWA 빌드입니다. 캐릭터 커스터마이징, 난이도별 스토리, 선택형 전투/회피, 저장, 히든 엔딩, 찐엔딩, WebAudio 기반 효과음, 반응형 UI를 포함합니다.

## 플레이

`index.html`을 정적 웹서버로 열면 됩니다. GitHub Pages, Netlify, Cloudflare Pages 등에서 그대로 호스팅할 수 있습니다.

로컬 실행 예시:

```bash
python -m http.server 8080
```

그 후 브라우저에서 `http://localhost:8080` 접속.

## 주요 기능

- 오프닝/설정/캐릭터 생성
- 성별, 피부색, 눈, 코, 입, 머리, 머리색, 옷 커스터마이징
- 0 키로 캐릭터 시점/플레이어 시점 전환
- 쉬움 / 일반 / 챌린저 3개 난이도
- HP, 공격력, 무기, 갑옷 내구도, 상태, 기분 HUD
- 쉬움: 영양사 귀신, 화장실 귀신, 감시자 히든 엔딩
- 일반: 안내견, 교장실, 과학실, 콩콩귀신 동료
- 챌린저: 케르베로스 퀴즈, 영어/수학/체육, 옥상, 마지막 50회 연타
- 자동 저장 / 수동 저장 / 이어하기
- 화면 흔들림, 깜짝 연출 강도, 동작 줄이기 설정
- 설치형 PWA 지원

## 조작

- 마우스: 조사 / 선택
- `0`: 시점 전환
- `Esc`: 대화창 닫기
- 메뉴: 저장, 설정, 로비로 이동

## 스토어 배포 전 체크

이 저장소는 **웹게임/PWA 기준 배포 가능한 구조**입니다. Google Play / App Store / Steam에 실제 등록하려면 각 플랫폼의 패키징과 서명, 스토어 심사 자료, 개인정보처리방침/등급 분류 등의 별도 절차가 필요합니다.
